Explore o GitHub Copilot em todo o ciclo de vida do desenvolvimento de software usando cenários realistas, um aplicativo completo e um backlog compartilhado. Você trabalhará iterativamente para planejar mudanças, criar código, testar comportamentos, revisar pull requests e gerenciar tarefas com agentes.

## Cenário

Você é um novo desenvolvedor da Tailspin Toys, uma empresa fictícia que financia jogos de tabuleiro com tema de desenvolvimento. O backlog da equipe já foi registrado como issues no GitHub, pronto para você assumir. Ele inclui trabalho de funcionalidade como filtragem e paginação, além de melhorias de qualidade como acessibilidade e padrões de codificação.

## Escolha seu ambiente

O GitHub Copilot atende você em qualquer ambiente de trabalho. Escolha o ambiente que mais combina com sua forma de construir. Cada workshop começa com sua própria configuração e usa o cenário compartilhado da Tailspin Toys.

### [GitHub Copilot CLI][cli]

Use o assistente baseado em agentes no terminal. Trabalhe com os modos Plan e Autopilot, instruções, skills, agentes personalizados, Playwright MCP, Agent Merge e comandos de barra práticos.

### [GitHub Copilot app][app]

Execute sessões paralelas de agentes, alterne os modos da sessão, colabore em canvases e gerencie issues e pull requests do GitHub no aplicativo desktop.

### [Agente de nuvem do GitHub Copilot][cloud]

Atribua issues do GitHub a um agente assíncrono, oriente seu trabalho, acompanhe o progresso e revise os pull requests que ele abre.

### [Visual Studio Code][vscode]

Use o GitHub Copilot no Visual Studio Code e no GitHub Codespaces. Trabalhe com o modo agente do Copilot Chat, servidores MCP e agentes personalizados sem sair do editor.
