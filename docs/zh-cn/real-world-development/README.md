在真实的软件开发生命周期中，使用更贴近生产场景的项目、完整应用和共享待办事项来探索 GitHub Copilot。你将反复规划改动、编写代码、测试行为、审查拉取请求，并通过智能体管理工作。

## 场景

你是一名新的 Tailspin Toys 开发者，这是一家虚构的桌游众筹公司，团队的待办事项已经整理成 GitHub 议题，随时可供你接手。这些议题包括筛选和分页等功能需求，以及无障碍和编码标准等质量改进。

## 选择你的环境

GitHub Copilot 会在你工作的任何地方出现。选择最适合你构建方式的环境。每个工作坊都从自己的设置开始，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用智能体助手。使用 Plan 和 Autopilot 模式、说明文件、技能、自定义智能体、Playwright MCP、Agent Merge 和实用的斜杠命令。

### [GitHub Copilot app][app]

在桌面应用中运行并行智能体会话、切换会话模式、协作画布，并管理 GitHub 议题和拉取请求。

### [GitHub Copilot cloud agent][cloud]

将 GitHub 议题分配给异步云端智能体，指导其工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 代理模式、MCP 服务器和自定义智能体。
